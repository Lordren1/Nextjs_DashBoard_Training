# Next.js Dashboard

A dashboard app. Includes authentication, a dashboard layout with navigation, and pages for viewing customers, invoices, and revenue.

## Tech Stack
- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## Getting Started

Install dependencies:
```bash
pnpm i
```

Run the dev server:
```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
